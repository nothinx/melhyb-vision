# Audit desain SIGMA, 11 September 2026

## Ruang lingkup dan status

Inspeksi seluruh delapan rute frontend aktif, komponen bersama, lapisan API,
data demo, dan kontrak analisis backend. Perbaikan dilakukan bertahap pada
komposisi, interaksi, dan kejujuran data. Backend penilaian tidak diubah.
Ini laporan implementasi dan verifikasi yang dilakukan, bukan sertifikasi
aksesibilitas atau klaim seluruh perangkat sudah diuji.

Catatan klik browser, localhost:5174 dalam mode demo:

- Navigasi delapan rute: halaman Ringkasan, Analisis, Riwayat, Kalibrasi,
  Standar, Katalog, Metode, dan Studi melon dirender.
- Menu ponsel: membuka seluruh tautan; navigasi menutup menu; Escape menutup
  dan mengembalikan fokus ke Menu.
- Tema: sistem, terang, dan gelap beralih; beranda diperiksa visual pada
  terang/gelap. Preferensi dikembalikan ke sistem.
- Susunan spesimen: Tertata/Tersebar mengubah susunan dan status terpilih;
  tombol putar kiri/kanan berfungsi.
- Riwayat: Tabel mengganti grafik dengan tabel; filter Melon hanya menampilkan
  lot melon. Lot #17 membuka hasil tanpa angka fisiologis, tombol Riwayat
  kembali ke daftar. Lot #16 menampilkan pesan rincian contoh tidak tersedia,
  bukan hasil lot lain.
- Pilihan komoditas Analisis dapat diubah. Tombol Berkas membuka alur pemilih,
  tetapi pengisian berkas oleh alat otomatis ditolak izin, sehingga unggahan
  dan hasil submit melalui browser belum terverifikasi.
- Ponsel 390 piksel: rute-rute diperiksa tanpa overflow halaman. Beranda
  diperiksa tambahan pada 320 dan 768 piksel serta desktop. Tabel lebar tetap
  memiliki wadah gulirnya sendiri. Ukuran browser dikembalikan setelah uji.

## Batas pemeriksaan dan lanjutan terarah

1. Kamera fisik, unggah nyata sampai hasil analisis, dan ekspor CSV dengan
   backend langsung masih perlu uji perangkat. Uji unit backend tidak
   menggantikan uji alur browser tersebut.
2. Reduced motion dan fallback WebGL sudah ditangani serta diperiksa di kode,
   belum diuji dengan emulasi perangkat. Tidak semua kontrol lama/tautan
   dokumen eksternal diklik satu per satu. Gerbang verifikasi penuh R-35
   belum diklaim selesai.
3. Bundle Three.js masih sekitar 555 KB minified (138 KB gzip), dimuat lewat
   impor dinamis. Build satu berkas sekitar 1,64 MB. Belum ada pengukuran
   Lighthouse atau ponsel kelas bawah; tidak ada klaim peningkatan kecepatan.
4. Masih terdapat tanda pisah panjang pada teks lama (R-02) dan peringatan
   React yang disebutkan di atas. Ini bukan laporan kelulusan anti-slop penuh;
   filter dipakai untuk perbaikan bertahap yang tercatat.
5. Pengelolaan varietas/batch dan autentikasi tetap mengikuti batas proyek
   semula. Tidak ditambah hanya untuk membuat tombol terlihat lengkap.

Hasil aplikasi bukan pengganti sertifikasi benih resmi. Parameter fisiologis
merupakan estimasi, bukan pengukuran; ukuran mm membutuhkan penanda skala.
